Tailwind 4.1 geometric texture spike

Updated around your narrowed set: plain grid, pluses, checks, diamonds, triangles, and hex grid, plus four research-driven candidate repeats from current CSS/Tailwind pattern libraries.

Core set: plain grid / pluses / checks / diamonds / triangles / hex grid
Candidates: cross-dots / zigzag / crosshatch / concentric squares
Separate grid + furniture colors where the motif supports both
Independent cell width + height

Proposed utility names

tx-base tx-plain-grid tx-pluses tx-checks tx-diamonds tx-triangles tx-hex-grid tx-cross-dots tx-zigzag tx-crosshatch tx-concentric-squares

Proposed variable contract

--tx-bg --tx-grid-color --tx-furniture-color --tx-cell-w --tx-cell-h --tx-grid-line --tx-mark-size --tx-mark-thickness

Expected usage shape

Why this updated set

  • Checks, diamonds, triangles, and pluses stay closest to the corner-furniture idea.
  • Hex grid is a very common geometric repeat in current CSS pattern collections and generators.
  • Cross-dots and zigzag are directly represented in established Tailwind/CSS pattern libraries.
  • Crosshatch and concentric squares are strong related repeats that show a different texture family without leaving the geometric space.
This artifact is the design and geometry decision surface. Once you choose proportions or motif swaps, the same variable model can be frozen into the production Tailwind 4.1 utilities.
